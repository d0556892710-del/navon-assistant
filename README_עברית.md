# נבון — עוזר AI שמפעיל את הטלפון

אפליקציית אנדרואיד שמקבלת פקודה בעברית (או אנגלית), חושבת באמצעות Claude,
ומבצעת אותה בפועל על המכשיר — פותחת אפליקציות, לוחצת, מקלידה וגוללת בתוך
כל אפליקציה (וואטסאפ, טלגרם, הגדרות וכו'). עובדת על ה-POCO X8 Pro Max עם HyperOS 3.

---

## מה צריך לפני שמתחילים

1. **מפתח API של Claude** — חשוב: זה **לא** אותו דבר כמו מנוי Claude Pro.
   את המפתח מקבלים ב-https://console.anthropic.com ← Settings ← API Keys.
   זה בתשלום לפי שימוש (טוענים קצת קרדיט מראש; כל פקודה עולה גרושים בודדים).
   המפתח נראה כך: `sk-ant-...`
2. **מחשב עם Android Studio** (חינמי) כדי לבנות את קובץ ה-APK.
   הורדה: https://developer.android.com/studio

---

## איך בונים את האפליקציה (פעם אחת)

1. פתח את Android Studio ובחר **Open**, ובחר את התיקייה `NavonAssistant`.
2. חכה ש-Gradle יסיים לסנכרן (יוריד את מה שצריך אוטומטית). אם הוא מבקש,
   אשר התקנת רכיבי SDK.
3. חבר את הפוקו בכבל USB, הפעל **ניפוי באגים USB** (Developer options ← USB debugging),
   או לחלופין בנה APK דרך **Build ← Build APK** והעבר אותו לטלפון.
4. לחץ על כפתור ה-Run (המשולש הירוק) כדי להתקין ולהריץ על המכשיר.

> אם Android Studio מתלונן שחסר `gradle-wrapper.jar`, זה נוצר אוטומטית
> כשפותחים את הפרויקט דרכו. אין צורך לעשות כלום ידנית.

---

## הגדרה ראשונית בטלפון (פעם אחת)

1. פתח את אפליקציית **נבון**.
2. לחץ **הגדרות**, הדבק את מפתח ה-API, ואם תרצה שנה את המודל
   (ברירת מחדל: `claude-sonnet-5-5` — מהיר וזול. למשימות קשות אפשר
   `claude-opus-4-8`). לחץ **שמור**.
3. נסה לשלוח פקודה — נבון יבקש להפעיל **הרשאת נגישות**.
   לחץ "פתח הגדרות" ← נגישות ← נבון ← הפעל.
4. **חשוב ל-HyperOS:** כדי שהמערכת לא תסגור את נבון באמצע משימה —
   הגדרות ← אפליקציות ← נבון ← חיסכון בסוללה ← **ללא הגבלות**.
   וגם: הגדרות ← אפליקציות ← נבון ← **הפעלה אוטומטית** ← מופעל.

---

## איך משתמשים

- כתוב או **הקלט בקול** (כפתור 🎤, בעברית) פקודה כמו:
  - "פתח וואטסאפ ושלח לאמא שאני בדרך"
  - "כבה את הבלוטות'"
  - "פתח יוטיוב וחפש מוזיקה רגועה"
- לחץ **בצע**. המסך יעבור למסך הבית ונבון יתחיל לעבוד.
  תוכל לעקוב אחרי הצעדים ביומן שבתוך האפליקציה.
- אם נבון צריך פרט חסר, הוא ישאל — פשוט ענה בשדה הפקודה ולחץ בצע שוב.
- כפתור **עצור** עוצר משימה באמצע.

### הפעלה בלחיצה ארוכה על כפתור הפעלה (אופציונלי)
הגדרות ← אפליקציות ← אפליקציות ברירת מחדל ← **עוזר דיגיטלי** ← בחר **נבון**.
מעכשיו לחיצה ארוכה על כפתור ההפעלה תפתח את נבון.

---

## איך זה בנוי (למתעניינים)

- `NavonAccessibilityService` — קורא את עץ המסך ומבצע לחיצות/הקלדה/גלילה.
- `ActionExecutor` — מתרגם פקודות (פתח אפליקציה, לחץ, הקלד…) לפעולות בפועל.
- `ClaudeClient` — שולח ל-Claude את מצב המסך ומקבל בחזרה את הפעולה הבאה (tool use).
- `AgentService` — שירות רקע (Foreground Service) שמריץ את הלולאה למשך זמן ארוך.
- `MainActivity` — הממשק, הקלט הקולי וההגדרות.

כל "המוח" רץ דרך ה-API של Claude, כך שהבנת עברית ואנגלית מצוינת.
המפתח נשמר מקומית במכשיר בלבד.

---

## הערות ובטיחות

- נבון מונחה לא לבצע פעולות מסוכנות (מחיקה, תשלום, שליחת כסף) בלי בקשה מפורשת,
  אבל כמו כל כלי אוטומציה — כדאי לפקוח עין בהתחלה.
- אם פעולה נכשלת, בדרך כלל זה כי שם האפליקציה או הכפתור שונה ממה שחשבת —
  נסח את הפקודה עם הטקסט המדויק שמופיע על המסך.
- זו אפליקציה אישית (sideload). אין צורך ב-root ואין צורך ב-ROM סיני.
